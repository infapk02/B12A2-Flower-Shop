# 🌸 Faugei Flower Shop

A modern and fully responsive flower shop landing page built with **HTML5** and **Tailwind CSS**. This project is a pixel-perfect implementation of a Figma design, focusing on clean layouts, responsive design, and modern UI components.

The website showcases a beautiful collection of flowers, promotional deals, and a newsletter subscription section while maintaining a seamless user experience across all devices. The project structure and technologies are evident from the provided HTML implementation.

## 📖 Overview

This project was developed as part of a responsive web design assignment where the goal was to convert a Figma design into a fully responsive landing page using only **HTML** and **Tailwind CSS**.

The website includes a responsive navigation bar, hero section, featured plants, promotional deals, newsletter subscription, and footer while maintaining a clean and modern design.
